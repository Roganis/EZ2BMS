# EZ2BMS user manual

This manual explains how to use EZ2BMS, the chart editor for EZ2PORT and EZ2AC cabinets, from
installing it to publishing your songs.

## How to read this

If you're new to EZ2BMS, read [Introduction](01-introduction.md), [Installing](02-installing.md)
and [Quick start](03-quick-start.md) in that order. After that, read the chapters you need as you
go: each one stands on its own and links to the others. The shortcuts are all in the
[key reference](../keybindings.md), and the words EZ2BMS uses are in the
[glossary](appendix-glossary.md).

On macOS, read Ctrl as Cmd.
